# Acoustic-Orders

აკუსტიკა.ge-ის ონლაინ შეკვეთების ექსპორტი Google Sheets-ში.

## გაშვება

```bash
# მიმდინარე ნახევართვე (ავტომატური 1-15 ან 16-31)
python3 orders_scraper.py

# კონკრეტული თარიღები
python3 orders_scraper.py --from 08/01/2026 --to 08/15/2026

# შითის ატვირთვის გარეშე (მხოლოდ CSV)
python3 orders_scraper.py --from 08/01/2026 --to 08/15/2026 --no-sheet
```

## ფაილები

- `orders_scraper.py` — მთავარი სკრიპტი
- `admin_client.py` — ადმინ პანელთან კომუნიკაცია (დალოგინება, მოთხოვნები)
- `parsers.py` — HTML-ის პარსინგი
- `sheet_uploader.py` — Google Sheets-ში ატვირთვა
- `config.py` — კონფიგურაცია
- `credentials.json` — Google Service Account

## მონაცემები

ყველა შეკვეთისთვის ამოიღება:
- ინვოისის №
- თარიღი
- სახელი გვარი
- პირადი/ორგანიზაციის ნომერი
- ტელეფონი
- თანხა (GEL)
- ბანკი (გადახდის მეთოდი)
- სტატუსი

## რეიტლიმიტი

- 3-5 წამი თითო შეკვეთის დეტალს შორის
- 5-8 წამი გვერდებს შორის
- 30-45 წამის cooldown 25 მოთხოვნაში ერთხელ
